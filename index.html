Chronote

매칭 · 실시간 채팅

같은 관심사를 가진 사람들을 연결하는 AI 매칭

관심 주제를 입력하면 한국어 임베딩으로 맞는 채팅방을 찾습니다. 적합한 방이 없으면 새로 만들고, 실시간 그룹 채팅으로 함께 공부합니다.

  • Spring Boot
  • FastAPI
  • React
  • MongoDB
구현 내용 +
  • FastAPI 한국어 임베딩 기반 채팅방 유사도 매칭
  • STOMP·WebSocket 실시간 그룹 채팅
  • MySQL 정형 데이터와 MongoDB 채팅 메시지 저장
  • Node.js·Express에서 Java·Spring Boot로 마이그레이션

UI 데모는 기존 학습 관리 화면입니다. 현재 저장소의 전체 백엔드 기능을 실행하는 데모는 아닙니다.
