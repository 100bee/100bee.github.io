01 / RAG & EVALUATION↗

RAGOps Copilot

설계·평가 MVP

출처와 실행 과정을 확인하는 장애 대응 RAG

운영 문서를 검색해 근거가 있는 대응 절차를 제안합니다. 검색 방식의 성능을 비교하고, 출처·지연시간·토큰을 함께 확인할 수 있도록 만들었습니다.

  • FastAPI
  • pgvector
  • Next.js
  • Gemini
구현 내용 +
  • 문서 업로드 → 마스킹 → 청킹 → 임베딩 → 검색 파이프라인
  • Vector·Keyword·Hybrid 검색 비교와 출처 ID 검증
  • 문서 12개·질문 20개의 작은 평가셋으로 검색·근거 판정 실험
  • 검색 후보, 지연시간, 토큰, Trace를 확인하는 진단 화면

검색 근거 판정에서 거절 대상 질문을 잘못 허용하는 한계를 기록했습니다. 실제 운영 서비스의 성과를 측정한 프로젝트는 아닙니다.
